# 智慧工厂跨任务会话计划

## 1. 总目标

- 以 `e:\ch\smart-factory\src` 为新的唯一产品原型来源
- 将新原型中的核心页面完整迁移为 Vue3 页面并纳入当前项目菜单与动态路由
- 页面数据全部通过后端接口获取，后端数据全部来自真实数据库
- 不使用前端硬编码业务数据，不使用 mock 数据伪造生产环境效果

## 2. 当前总体策略

- 采用“完整迁移计划 + 分阶段实施”模式推进
- 先锁定全量目标页面与模块边界，再按优先级逐页落地
- 总览页作为第一优先级，但不再把其他页面排除出总体规划
- 菜单、路由、页面目录、数据接口、数据库来源统一纳入一个跨任务计划

## 4. 跨任务阶段计划

### 阶段 1：总览页与数据聚合

- 新增智慧工厂总览后端聚合接口
- 用真实数据库构建总览所需指标、趋势、告警、环境、视频入口数据
- 重构 `Overview/index.vue` 贴近 `smart-factory` 的 `Dashboard` 原型

### 阶段 2：菜单对齐与完整页面入口

- 输出智慧工厂模块完整菜单清单
- 将智慧工厂菜单重构为 9 个一级业务入口
- 为原型中确定要落地的页面补齐 Vue 页面承接位
- 与后端菜单配置方案对齐，确保动态路由可以完整挂载

### 阶段 3：业务子页逐页迁移

- 按业务优先级迁移生产、环境、能耗、安全、视频等子页
- 能复用当前项目公共能力的优先复用
- 页面先完成结构与真实接口接入，再做细节增强

### 阶段 4：公共能力沉淀

- 继续沉淀视频播放层、视图管理、设备树等公共能力
- 将智慧工厂专区内的新组件收敛为可复用的公共组件与 composable

### 阶段 5：菜单落地与联调收尾

- 生成最终菜单与路由映射表
- 联调真实数据库、真实接口、真实菜单
- 逐页验收与缺口收敛
