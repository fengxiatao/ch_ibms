# 智慧工厂视频融合页面重构设计

## 1. 目标

- 以 `e:\ch\smart-factory\src\components\pages\VideoFusion.tsx` 作为视频融合页面的唯一视觉原型来源
- 在当前 Vue3 项目中全新重建视频融合工作台，使页面结构、视觉分区、交互节奏与原型一致
- 顶部必须显式提供 `实时视频`、`视频回放`、`AI识别` 三个业务 Tab，且作为页面内部工作模式切换入口
- 虽然展示层完全新建，但底层继续承接当前项目已存在的真实联动、播放器、视频墙与流创建能力
- 页面继续采用 Vue3 原生实现，不使用 iframe，不回退到 mock 演示壳

## 2. 范围

### 2.1 本期包含

- 重构 `src/views/factory/dashboard/Video/index.vue` 的页面主结构
- 保留 `src/views/factory/videoFusion/index.vue` 作为正式入口，不调整已有菜单和路由挂载
- 以原型方式重建顶部三 Tab、工具栏、左侧视频网格区和右侧摄像头列表区
- 重新组织实时流、回放流、AI识别态在同一工作台中的承接方式
- 复用现有 `FactoryStreamPlayer`、`FactoryVideoWall`、联动参数解析与真实流创建链路
- 为三种模式建立统一状态模型，保证上游联动进入后的行为一致

### 2.2 本期不包含

- 新增后端接口或伪造业务成功态
- 引入与当前项目无关的第三方播放器体系
- 将视频融合页面拆成三个独立路由页面
- 在本轮内补齐所有高级播放能力，如云台、轮巡、录像时间轴等尚未落地的深层交互

## 3. 原型与当前承接关系

### 3.1 原型来源

- 原型工程：`e:\ch\smart-factory\src`
- 目标页面：`e:\ch\smart-factory\src\components\pages\VideoFusion.tsx`

### 3.2 当前承接页

- 页面入口：`src/views/factory/videoFusion/index.vue`
- 当前实现页：`src/views/factory/dashboard/Video/index.vue`
- 当前真实能力组件：`src/components/FactoryDashboard/FactoryStreamPlayer.vue`
- 当前视频墙组件：`src/components/FactoryDashboard/FactoryVideoWall.vue`
- 当前联动 query 协议：`src/composables/factory/useFactoryVideoLink`
- 当前视频流接口：`src/api/iot/video/stream`

### 3.3 当前问题

- 现状页面采用 `hero + 联动上下文 + 联动播放器 + 轻量视频墙` 的纵向堆叠结构
- 当前结构本质更像“能力说明页”，与原型的工作台布局不匹配
- 页面缺失顶部三 Tab 业务切换、左右主从分区、原型式视频卡片矩阵和右侧列表工作区
- 虽然已有真实流能力，但被旧展示层包裹后难以对齐产品原型

## 4. 页面结构设计

### 4.1 总体布局

- 页面采用单页工作台布局，不再复用旧页面纵向分段作为主界面
- 页面主骨架固定为四段：
  - 顶部业务 Tab 区
  - 次级工具栏区
  - 左侧主视频区
  - 右侧点位侧栏区
- 页面首屏必须直接展示完整工作台，不让用户先看到说明性 hero 或能力面板

### 4.2 顶部业务 Tab

- 固定提供三个 Tab：`实时视频`、`视频回放`、`AI识别`
- Tab 是页面内部业务模式切换，不通过切换左侧菜单或跳转到不同路由实现
- 三个 Tab 的视觉形式、激活态和图标节奏向原型靠拢
- 当前激活 Tab 需要参与页面状态管理与上游联动承接

### 4.3 工具栏

- 位于 Tab 下方，作为工作台次级操作区
- 左侧至少包含搜索框与区域筛选
- 右侧根据当前模式显示附加操作入口，如刷新、视图切换、AI叠加开关等
- 工具栏是业务操作区，不再承载旧页面“刷新联动流”单按钮的孤立呈现方式

### 4.4 左侧主视频区

- 采用原型式卡片视频矩阵作为默认主展示形态
- 支持网格视图和主卡聚焦视图
- 每个视频卡片展示通道名称、位置、在线状态和模式相关标签
- 实时模式下强调在线态、快速播放与联动告警
- 回放模式下强调时间窗、录像命中状态和回放播放状态
- AI模式下强调识别状态、风险标签、命中信息和叠加态表现

### 4.5 右侧侧栏

- 右侧独立为摄像头/点位工作区，不再下沉到页面底部或混入说明面板
- 展示摄像头列表、位置分组、状态摘要与当前选中项
- 列表项点击后驱动左侧视频区切换，不是仅做静态展示
- 右侧列表需支持与搜索、区域筛选和上游联动上下文联动

## 5. 三个 Tab 的真实链路设计

### 5.1 实时视频

- 实时视频为主工作模式，优先承接现有真实联动链路
- 继续解析当前 query 中的 `mode`、`deviceId`、`sourceId`、`sourceName`、`location` 等参数
- 实时单卡播放继续复用 `FactoryStreamPlayer`
- 多卡矩阵与分屏展示继续复用 `FactoryVideoWall` 和其底层网格能力
- 从驾驶舱或告警页联动进入时，默认优先定位对应设备并触发实时流创建

### 5.2 视频回放

- 回放模式不再只是实时页的文案变体，而是工作台中的独立业务模式
- 继续承接现有 query 中的 `startTime`、`endTime`、`alarmTime` 等时间信息
- 回放流创建继续复用当前 `getPlaybackStream` 链路
- 页面工具栏需提供回放相关的时间定位与刷新入口
- 卡片与右侧列表的语义切换为录像可用性、回放命中状态与回放播放视角

### 5.3 AI识别

- AI识别也继续使用真实视频源承接，而不是单做静态页面
- 页面沿用工作台壳，但卡片、标签、右侧侧栏切换为识别业务语义
- 当前已有联动设备或告警上下文时，应能够映射到识别模式下的重点展示对象
- 若当前项目缺少某类识别结果数据，则保留真实空态和待接入态，不伪造命中结果
- AI模式与实时/回放共享播放器能力，但增加识别标签、风险等级和结果摘要层

## 6. 状态模型与交互设计

### 6.1 统一状态模型

- 页面维护统一的工作台状态，而不是三个 Tab 各自维护割裂状态
- 统一状态至少包含：
  - 当前模式
  - 当前选中设备或点位
  - 当前搜索词
  - 当前区域筛选值
  - 当前时间窗
  - 当前联动来源与上下文
  - 当前视图模式
- 模式切换时优先保留选中对象与上下文，减少用户重复操作

### 6.2 页面交互

- 点击顶部 Tab：切换模式、工具栏内容、卡片语义和右侧列表状态，但不离开当前工作台
- 点击右侧列表项：驱动左侧主视频区聚焦对应设备，并触发实时流或回放流加载
- 从驾驶舱或告警页联动进入：自动定位目标设备、切换到合适模式并高亮右侧条目
- 搜索与区域筛选：同时作用于右侧列表与左侧卡片集合
- 当真实链路缺少必要参数时，页面展示明确空态，不伪造成功播放

### 6.3 安全降级

- 缺少 `deviceId` 时，不发起错误的真实流请求
- 回放模式缺少开始或结束时间时，不伪造录像结果
- AI模式缺少识别结果数据时，保留播放器和业务壳，但显示真实待接入态
- 未落地高级能力仅保留可解释的入口，不提供虚假交互结果

## 7. 组件与职责拆分

- `Video/index.vue`：作为新页面主装配层，负责工作台布局、状态编排和模式切换
- 新增顶部 Tab 组件：负责三个业务模式的切换与激活态展示
- 新增工具栏组件：负责搜索、筛选、模式附加操作和状态入口
- 新增视频网格组件：负责左侧卡片矩阵与主卡聚焦模式
- 新增视频卡片组件：负责单卡展示与模式化标签渲染
- 新增右侧侧栏组件：负责设备列表、分组、状态摘要与点击选择
- 现有 `FactoryStreamPlayer` 和 `FactoryVideoWall` 保持为底层真实播放能力提供者，不再决定页面主结构

## 8. 迁移策略

### 8.1 展示层完全重建

- 当前 `Video/index.vue` 的纵向 panel 页面结构不作为最终 UI 保留
- 旧页面只保留真实链路相关逻辑，不继续承担主展示壳职责
- 新展示层按原型完全新建，确保三 Tab 与左右布局一次到位

### 8.2 能力层抽离复用

- 从旧页面中抽离联动参数解析逻辑
- 从旧页面中抽离实时流与回放流创建逻辑
- 从旧页面中抽离视频源适配与视频墙映射逻辑
- 新页面只消费抽出的能力，不直接继承旧页面的纵向视图结构

### 8.3 路由和菜单保持稳定

- 不调整 `/factory/video-fusion` 既有菜单与路由
- 保持上游跳转链接和 query 协议兼容，避免影响驾驶舱与告警页已有联动
- 入口稳定，内部重构，减少对外部页面的连锁影响

## 9. 风险与约束

- 原型是高保真工作台，而当前真实能力以底层组件为主，页面层需要重新编排
- AI识别模式的真实业务数据可能不如实时和回放完整，需要接受阶段性空态
- 若现有视频墙能力以轻量展示为主，则新页面需要在不破坏底层的前提下重新包装视图
- 页面首屏信息量大，需保证 `1920x1080` 下可读，不出现普通后台页面式挤压

## 10. 验收标准

- 页面顶部明确存在三个 Tab，且视觉和结构与原型一致
- 页面主布局为原型式工作台：顶部工具区、左侧视频矩阵、右侧摄像头列表
- 三个 Tab 均能承接真实联动上下文，不是纯静态占位
- 实时、回放、AI三种模式均复用当前项目的真实联动和播放能力链路
- 从驾驶舱和告警页进入视频融合页时，目标设备能够被正确承接和定位
- 缺少参数或能力时页面显示真实空态，不使用 mock 或硬编码假成功
- 页面继续以 Vue3 原生实现，不使用 iframe
